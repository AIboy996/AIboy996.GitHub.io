# 奇闻旧事

我是一个**不擅长记忆却又无比念旧的人**，所以写了很多文字、拍了很多照片，想尽可能地留下珍贵回忆的索引。

然而在人生的前十几年，我并不是如此。那时候的我记忆力超群，讨厌拍照也不喜欢回忆过去。所以2019年以及更早的事情都无从说起了。不知道是因为我老了，还是因为现实生活中的信息洪流已经把我淹没。最近我感觉我的高中、我的本科生活都有些模糊。不过好在那些东西还差不多有迹可循。

有趣的是，在平淡的日常里一些无规则的记忆碎片会突然涌现。我不愿任由它们再次被淹没，因此把他们记录了下来。当然为了贴合“奇闻旧事”的主题，也会有其他东西混入其中。

以下就是那些奇闻旧事：

- 我有两个亲姐姐，但是她们俩之间完全**没有血缘关系**
    - 听起来就很神秘有没有
- 我们家曾经是喝**甜的**西红柿蛋汤的
    - 现在倒是不怎么喝了
- 我们家的汤圆有两种特制馅料：红糖**核桃** 以及 红糖**紫苏籽**
    - 每年过年都是这么吃的
- 家传技艺：土豆可以用**酒瓶盖**来去皮
- 我妈曾经老喜欢让我用牙来给她**开啤酒**
    - 这直接导致我的右侧第一前磨牙已经崩了一个角
- 很长一段时间，我的爷爷奶奶外公外婆同时住在我们家
    - 矛盾非常多，但是爷爷奶奶走后就不存在这些矛盾了
- 我的外婆有一个虚拟的“补助账户”
    - 定期往里打钱的其实是我妈
- 有好几个夏天，我们家洗澡的时候都是用**太阳晒的水**
    - 并不是太阳能热水器，而是真的拿一个大盆接水后放在太阳底下暴晒，现在想来也是别有异趣
- 我从很小的时候就开始**上网吧**，至今也会没事就去网吧坐一坐
    - 清晰地记得，第一次上网是在六年级的暑假，我去网吧玩了一下午洛克王国
- 曾经有一次我被我妈按在地上跪着、暴打了一顿
    - 被打的原因现在想来非常可笑：我拉着楼下的小朋友合资买了一台手机天天打游戏被发现了
- 我只在初中升高中的暑假上过一次补习班
    - 唯一这去补习班也不是为了补课，只是因为在意的女生也去了那个补习班，属于是不务正业
